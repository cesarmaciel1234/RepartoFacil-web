# Asistente y Flujos de IA (`src/ai/`)

## 1. Qué hace
Define herramientas y flujos de inteligencia artificial mediante el framework Google Genkit para recomendaciones de productos y asistencia contextual al comprador.

## 2. De dónde viene
- Llamadas desde componentes de asistente virtual o búsqueda inteligente.

## 3. Subdirectorios
- `flows/`: Flujos conversacionales y razonamiento de sugerencias.
- `tools/`: Herramientas de consulta de catálogo e inventario para el modelo de lenguaje.

## 4. Hacia dónde sale
- Hacia la API de Google Gemini / Genkit y la interfaz de chat con el comprador.
