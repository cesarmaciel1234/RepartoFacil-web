# Componentes de Dashboard (`src/components/dashboard/`)

## 1. Qué hace
Widgets, tarjetas estadísticas y paneles de visualización de indicadores (KPIs de ventas, pedidos activos y estado operativo).

## 2. De dónde viene
- Consumidos en vistas administrativas o paneles de control de tiendas y choferes.

## 3. Archivos principales
- `MetricCard.tsx`: Tarjeta de resumen de valor numérico con comparativa porcentual.
- `OrdersOverview.tsx`: Tabla compacta con el resumen de pedidos recientes.

## 4. Hacia dónde sale
- Hacia la pantalla del operador o panel de administración.
